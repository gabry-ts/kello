Kello now shares one design with Tuuli, Kaiku, Kiito and Mittari. The popover, the event and reminder editors, Settings and About are built from the same components as the other apps, so buttons, switches, cards and the settings window look and behave the same everywhere.

The popover has a new footer with Settings, a ⋯ menu for updates, upcoming days, calendars and Buy Me a Coffee, and Quit. Controls that can't be used right now are dimmed instead of looking active, and the Join button in event rows is a compact version of the one in the Next up card.

Settings uses the shared window with a sidebar, and About now holds the updates switch and the version.

Nothing changes in how Kello reads your calendars and reminders, and no new permissions are needed.
