Kello's first public release: a calendar for the menu bar, with a month grid, an agenda, reminders, and events you can create, edit and join without leaving the popover.

The month grid shows week numbers and holidays if you turn them on, and the agenda leads with a "Next up" card for whatever's coming next today, with a one-click Join button when it's a call. Quick entry parses plain text like "Lunch with Sara friday 1pm" into a real event. A global shortcut brings Kello up from any app, and it can show extra time zones alongside your own.

Kello is signed with a Developer ID and notarized by Apple, so there's no quarantine warning to work around: download the DMG, drag Kello to Applications, and open it.

This release also adds automatic updates. Kello checks GitHub for new releases and asks, the first time it can, whether you'd like it to check automatically from then on; you can change that later in Settings > About. Updates download and install in the background.

Kello asks for calendar and reminders access on first launch and only ever reads and writes them through EventKit. Nothing else leaves your Mac, and the only network access is the update check itself.

The app is available in English and Italian, following your system language.

If you'd like to support the project, there's a "Buy Me a Coffee" link in the popover's more menu and in Settings > About.
